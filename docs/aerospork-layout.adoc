:manpurpose: Change the layout of the focused window, or float it

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork layout [-h|--help] [--window-id <window-id>]
                 (h_tiles|v_tiles|h_accordion|v_accordion|tiles|accordion|horizontal|vertical|tiling|floating)...

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`layout` changes the layout or the orientation of the container that holds the focused window, or makes the window float or tile.

With several arguments, `layout` applies the first argument that does not match the current layout.
So two arguments toggle between them, and the order of the arguments does not matter.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

--window-id <window-id>::
include::util/window-id-flag-desc.adoc[]

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

h_tiles, v_tiles, h_accordion, v_accordion:: Set the layout and the orientation of the container.
tiles, accordion:: Set the layout of the container, and keep its orientation.
horizontal, vertical:: Set the orientation of the container, and keep its layout.
tiling, floating:: Make the window tile or float.

Old spellings, still accepted: `list`, `h_list` and `v_list` for `tiles`, `h_tiles` and `v_tiles`.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`layout` exits 1 when no window is focused, and for a minimized window, a macOS fullscreen window or a window of a hidden app.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Toggle between floating and tiling: +
`aerospork layout floating tiling`
* Toggle the orientation: +
`aerospork layout horizontal vertical`
* Toggle between `tiles` and `accordion`: +
`aerospork layout tiles accordion`
* Switch to `tiles`. When the container is already `tiles`, toggle its orientation: +
`aerospork layout tiles horizontal vertical`
