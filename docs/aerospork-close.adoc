// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork close [-h|--help] [--quit-if-last-window] [--window-id <window-id>]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`close` closes a window as its close button does. The app can ask you to save first, so the window can stay open.

For the focused window, macOS already offers cmd-w, so you do not need this command in a binding.
Use it from a script, or with `--window-id` to close a window that does not have focus.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.
--quit-if-last-window:: When the window is the last window of its app, quit the app.

--window-id <window-id>::
include::util/window-id-flag-desc.adoc[]

// =========================================================== Exit status
include::util/exit-status.adoc[]

`close` exits 1 on an empty workspace, and when the app does not quit.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Close every TextEdit window, on every monitor: +
`aerospork list-windows --monitor all --app-bundle-id com.apple.TextEdit --format '%{window-id}' | xargs -n1 aerospork close --window-id`
