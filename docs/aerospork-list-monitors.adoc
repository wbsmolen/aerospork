// =========================================================== Description
== Description

// tag::body[]
`list-monitors` prints one line for each connected monitor, in monitor order.
include::util/monitor-order.adoc[]
The filters narrow the list.

Use `--format '%{monitor-fingerprint}'` to get the table that pins a workspace to one physical monitor in `[monitors]`.

include::util/cli-only.adoc[]

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

--focused [no]::
Print only the focused monitor. With `no`, print every other monitor.

--mouse [no]::
Print only the monitor with the mouse pointer. With `no`, print every other monitor.

:list-noun: monitors

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Print every monitor in the default format: +
`aerospork list-monitors`
* Print the monitor fingerprints, to paste into `[monitors]`: +
`aerospork list-monitors --format '%{monitor-fingerprint}'`
* Print the vendor ID, the model ID and the size of each monitor: +
`aerospork list-monitors --format '%{monitor-name} [%{monitor-vendor-id}:%{monitor-model-id}] %{monitor-width}x%{monitor-height}'`
