== Synopsis

aerospork list-apps [-h|--help] [--macos-native-hidden [no]] [--format <output-format>] [--count] [--json]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`list-apps` prints the running apps that appear in the Dock and can have a user interface, one line for each app.
Use it to find the bundle ID of an app for a https://aerospork.app/docs/guide.html#on-window-detected-callback[window rule].

include::util/cli-only.adoc[]

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

--macos-native-hidden [no]::
Print only the apps hidden with cmd-h. With `no`, print only the apps that are not hidden.

:list-noun: apps

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Print the bundle ID and the name of every app: +
`aerospork list-apps --format '%{app-bundle-id}%{right-padding} %{app-name}'`
