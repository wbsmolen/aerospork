= aerospork-reload-config(1)
include::util/man-attributes.adoc[]
:manname: aerospork-reload-config
// tag::purpose[]
:manpurpose: Read the config again and apply it
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork reload-config [-h|--help] [--no-gui] [--dry-run]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`reload-config` reads the config file again and applies it.
You rarely need it: AeroSpork already reloads the config when the file changes, from an editor or from the Settings window.

When the config has errors, AeroSpork keeps the config that it runs now.
The command prints the errors to stdout and opens an error window.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.
--no-gui:: Do not open the error window. Print the errors to stdout only.
--dry-run:: Check the config and print its errors, but do not apply it.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`reload-config` exits 1 when the config has errors.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Check the config from a script, with no window: +
`aerospork reload-config --dry-run --no-gui && echo 'The config is valid'`
* Reload the config and go back to the main binding mode:
+
[source,toml]
----
[keys.service]
esc = ['reload-config', 'mode main']
----
