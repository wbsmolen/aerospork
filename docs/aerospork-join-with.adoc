// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork join-with [-h|--help] [--window-id <window-id>] (left|down|up|right)

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`join-with` puts the focused window and its neighbor in that direction into a new `tiles` container.
The neighbor is the nearest node in that direction: a window, or a container.
The new container takes the place of the neighbor, with the opposite orientation of its parent.

`join-with` replaces the https://i3wm.org/docs/userguide.html#_splitting_containers[split command] of i3.
You split a node almost always to put several windows under one parent, and `join-with` does that in one step.
Unlike `split`, it works with https://aerospork.app/docs/guide.html#normalization[`enable-normalization-flatten-containers`] on.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

--window-id <window-id>::
include::util/window-id-flag-desc.adoc[]

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

(left|down|up|right):: The direction of the neighbor to join.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`join-with` exits 1 when no window is focused, and when there is no node in that direction.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Given this layout
+
----
h_tiles
├── window 1
├── window 2 (focused)
└── window 3
----
+
`join-with right` gives this layout
+
----
h_tiles
├── window 1
└── v_tiles
    ├── window 2 (focused)
    └── window 3
----
