= aerospork-focus-back-and-forth(1)
include::util/man-attributes.adoc[]
:manname: aerospork-focus-back-and-forth
// tag::purpose[]
:manpurpose: Focus the window or empty workspace that had focus before
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork focus-back-and-forth [-h|--help]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`focus-back-and-forth` focuses whatever had focus before: a window, or an empty workspace.
Run it twice to go back to where you started.

AeroSpork remembers only one previous focus.
When you close the window that had focus before, `focus-back-and-forth` has nothing to go back to and exits 1.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`focus-back-and-forth` exits 1 when the previous window is closed.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Go back to the previous window, or else to the previous workspace: +
`aerospork focus-back-and-forth || aerospork workspace-back-and-forth`
+
The second command also fails when there is no previous workspace yet.
