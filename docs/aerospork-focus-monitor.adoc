= aerospork-focus-monitor(1)
include::util/man-attributes.adoc[]
:manname: aerospork-focus-monitor
// tag::purpose[]
:manpurpose: Focus a monitor by direction, by order, or by pattern
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork focus-monitor [-h|--help] [--wrap-around] (left|down|up|right)
aerospork focus-monitor [-h|--help] [--wrap-around] (next|prev)
aerospork focus-monitor [-h|--help] <monitor-pattern>...

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`focus-monitor` focuses the visible workspace of another monitor, and the window on it that had focus last.
No window moves.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.
--wrap-around:: At the last monitor, go on to the first, and the reverse. Incompatible with `<monitor-pattern>`.

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

(left|down|up|right)::
The nearest monitor in that direction from the focused monitor.

(next|prev)::
The next or the previous monitor in monitor order.
include::util/monitor-order.adoc[]

include::util/monitor-pattern-arg.adoc[]

// =========================================================== Exit status
include::util/exit-status.adoc[]

`focus-monitor` exits 1 when no monitor is in that direction or in that position, and when no pattern matches.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Focus the monitor to the right, and wrap to the leftmost one: +
`aerospork focus-monitor --wrap-around right`
* Focus the built-in display if it is connected, else the main monitor: +
`aerospork focus-monitor 'built-in' main`
