= aerospork-volume(1)
include::util/man-attributes.adoc[]
:manname: aerospork-volume
// tag::purpose[]
:manpurpose: Change or mute the system output volume
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork volume [-h|--help] (up|down)
aerospork volume [-h|--help] (mute-toggle|mute-off|mute-on)
aerospork volume [-h|--help] set <number>

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`volume` changes the output volume of the Mac, as the volume keys do.
Bind it to keys on a keyboard that has no media keys.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

up, down:: Make the volume louder or quieter by one step of 6.25% (1/16), the step of the media keys.
mute-toggle:: Mute the output, or unmute it when it is muted.
mute-on:: Mute the output.
mute-off:: Unmute the output.
set <number>:: Set the volume to `<number>`, from 0 to 100.

// =========================================================== Exit status
include::util/exit-status.adoc[]

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Set the volume to one quarter: +
`aerospork volume set 25`
* Control the volume with bindings:
+
[source,toml]
----
[keys]
alt-shift-up = 'volume up'
alt-shift-down = 'volume down'
alt-shift-m = 'volume mute-toggle'
----
