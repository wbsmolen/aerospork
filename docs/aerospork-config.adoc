// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork config [-h|--help] --get <name> [--json] [--keys]
aerospork config [-h|--help] --major-keys
aerospork config [-h|--help] --all-keys
aerospork config [-h|--help] --config-path

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`config` prints the effective config: what AeroSpork runs now, after it expands the file.
For example, `--get mode.main.binding` lists the generated bindings and the bindings that you wrote.

The config is a tree of maps, arrays, strings and integers.
Without `--json` or `--keys`, `--get` prints only a string, an integer or an array of them.
For a map or an array of maps, add `--json` or `--keys`.

include::util/cli-only.adoc[]

AeroSpork reads its config from `~/.aerospork.toml` or `$XDG_CONFIG_HOME/aerospork/aerospork.toml`.
When `XDG_CONFIG_HOME` is not set, the second path is `~/.config/aerospork/aerospork.toml`.
When both files exist, AeroSpork reports a config error.
A debug build reads `~/.aerospork-debug.toml` or `$XDG_CONFIG_HOME/aerospork/aerospork-debug.toml`.
When you start AeroSpork.app with `--config-path <path>`, it reads that file instead.

`aerospork config --config-path` prints the path of the file that the running app loaded.
When you have no config of your own, that is the default config inside the app.

For the v1 and v2 spellings of the config, and how AeroSpork converts a v1 config, see
https://aerospork.app/docs/guide.html#config-v2[the guide].

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.
--get <name>:: Print the value of `<name>`. `--major-keys` and `--all-keys` list the names.
--major-keys:: Print the top-level names.
--all-keys:: Print every name, at every level.
--json:: Print the value as JSON. Requires `--get`.
--keys:: Print the keys of a map, or the indexes of an array. Requires `--get`.
--config-path:: Print the absolute path of the config that the running app loaded.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`config --get` exits 1 when `<name>` is not in the config.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Print the path of the config that AeroSpork loaded:
+
----
$ aerospork config --config-path
/Users/you/.aerospork.toml
----
* List the binding modes:
+
----
$ aerospork config --get mode --keys
main
service
----
* List the bindings of the `main` binding mode:
+
----
$ aerospork config --get mode.main.binding --keys
alt-1
alt-2
...
----
* Print the bindings of the `main` binding mode as JSON:
+
----
$ aerospork config --get mode.main.binding --json
{
  "alt-1" : "workspace 1",
  "alt-shift-1" : "move-node-to-workspace 1",
...
----
