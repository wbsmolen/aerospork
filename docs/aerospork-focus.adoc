:manpurpose: Focus the nearest window in a direction

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork focus [-h|--help] [--ignore-floating]
                [--boundaries <boundary>] [--boundaries-action <boundary-action>]
                (left|down|up|right)
aerospork focus [-h|--help] --window-id <window-id>
aerospork focus [-h|--help] --dfs-index <dfs-index>

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`focus left` focuses the nearest window to the left of the focused window, and so on for the other directions.
By default `focus` stays inside the focused workspace: at its edge, nothing happens.
`--boundaries` and `--boundaries-action` change what happens at the edge.

Unlike i3, `focus` has no separate argument for floating windows.
It treats each floating window as part of https://aerospork.app/docs/guide.html#floating-windows[the tree], at its position on the screen, so one binding reaches every window.
`--ignore-floating` turns that off.

`focus` has no `child` or `parent` argument.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

--boundaries <boundary>::
Where the edge is. The default is `workspace`.
+
* `workspace`: the edge of the focused workspace.
* `all-monitors-outer-frame`: the outer edge of all monitors together. At the edge of a monitor inside that frame, focus goes to the next monitor in that direction.

--boundaries-action <boundary-action>::
What happens at the edge. The default is `stop`.
+
* `stop`: nothing changes, and the command exits 0.
* `fail`: nothing changes, and the command exits 1.
* `wrap-around-the-workspace`: focus the window at the opposite edge of the workspace.
* `wrap-around-all-monitors`: focus the monitor at the opposite end. This action requires `--boundaries all-monitors-outer-frame`, so AeroSpork rejects `focus --boundaries-action wrap-around-all-monitors left` alone.

--window-id <window-id>::
Focus the window with this ID, on any workspace.
A minimized window, or a window of a hidden app, comes back first.
Incompatible with every other option.

--dfs-index <dfs-index>::
Focus the window at this position in a depth-first walk of the tiled windows of the focused workspace. The first window is 0.
Incompatible with every other option.

--ignore-floating::
Leave floating windows out of the tree. A script then gets the same result whatever floats.

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

(left|down|up|right):: The direction to look for a window in.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`focus` exits 1 when no window is focused, when no window has the ID or the index, and at the edge with `--boundaries-action fail`.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Move focus across monitors, and wrap from the last monitor to the first: +
`aerospork focus --boundaries all-monitors-outer-frame --boundaries-action wrap-around-all-monitors right`
* Focus the first tiled window of the workspace: +
`aerospork focus --dfs-index 0`
