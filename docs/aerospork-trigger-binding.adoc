= aerospork-trigger-binding(1)
include::util/man-attributes.adoc[]
:manname: aerospork-trigger-binding
// tag::purpose[]
:manpurpose: Run a binding as if you pressed its keys
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork trigger-binding [-h|--help] <binding> --mode <binding-mode>

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`trigger-binding` runs the commands of a binding without a key press.
The binding mode does not have to be the active one.

To list the bindings of a mode, run `aerospork config --get mode.main.binding --keys`.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.
--mode <binding-mode>:: The binding mode that holds `<binding>`. Required.

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

<binding>:: The keys of the binding, in the key notation of the config, for example `alt-tab`.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`trigger-binding` exits 1 when the mode or the binding does not exist, and when a command of the binding fails.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Run the `alt-tab` binding of the `main` mode: +
`aerospork trigger-binding --mode main alt-tab`
* Run the first binding of the `main` mode, in alphabetical order: +
`aerospork trigger-binding --mode main "$(aerospork config --get mode.main.binding --keys | head -1)"`
