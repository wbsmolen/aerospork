// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork list-workspaces [-h|--help] --monitor <monitor>... [--visible [no]] [--empty [no]] [--format <output-format>] [--count] [--json]
aerospork list-workspaces [-h|--help] --all [--format <output-format>] [--count] [--json]
aerospork list-workspaces [-h|--help] --focused [--format <output-format>] [--count] [--json]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`list-workspaces` prints the name of each workspace that matches every filter, one name for each line.
Give one of `--monitor`, `--all` and `--focused`.

A workspace that the config declares always exists, even while it is empty, so `--all` always prints it.
For which workspaces exist, see https://aerospork.app/docs/guide.html#persistent-workspaces[the guide].

include::util/cli-only.adoc[]

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

include::util/all-monitors-option.adoc[]

--focused::
Alias for `--monitor focused --visible`. Always prints one workspace.

include::util/monitor-option.adoc[]

--visible [no]::
Print only the visible workspaces, one for each monitor. With `no`, print only the workspaces that are off screen.

--empty [no]::
Print only the empty workspaces. With `no`, print only the workspaces that have windows.

:list-noun: workspaces

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Print the focused workspace: +
`aerospork list-workspaces --focused`
* Print the workspaces with windows on the focused monitor: +
`aerospork list-workspaces --monitor focused --empty no`
* Print each workspace with the monitor that it is on: +
`aerospork list-workspaces --all --format '%{workspace}%{right-padding} %{monitor-name}'`
