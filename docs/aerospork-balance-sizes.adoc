= aerospork-balance-sizes(1)
include::util/man-attributes.adoc[]
:manname: aerospork-balance-sizes
// tag::purpose[]
:manpurpose: Give the windows of the focused workspace equal sizes
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork balance-sizes [-h|--help] [--workspace <workspace>]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`balance-sizes` gives every window and container in a `tiles` layout an equal share of its parent container.
Use it after a `resize` to go back to an even split.

Windows in an `accordion` layout and floating windows keep their size.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

--workspace <workspace>::
include::util/workspace-flag-desc.adoc[]

// =========================================================== Exit status
include::util/exit-status.adoc[]

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Even out the focused workspace: +
`aerospork balance-sizes`
* Even out workspace `2`, visible or not: +
`aerospork balance-sizes --workspace 2`
