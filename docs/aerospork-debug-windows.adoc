== Synopsis
[verse]
// tag::synopsis[]
aerospork debug-windows [-h|--help] [--window-id <window-id>]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`debug-windows` records what the macOS Accessibility API reports about windows.
Attach its output to a bug report about a window that AeroSpork handles wrongly, for example a window that floats when it should tile.

To record a session:

. Run `aerospork debug-windows`. The recording starts.
. Focus the problem window, or make the window appear.
. Run `aerospork debug-windows` again. The recording stops and the command prints what it recorded.

`debug-windows` is not a stable API.
Do not rely on the command, or on its output format, in a script.

include::util/cli-only.adoc[]

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

--window-id <window-id>::
Print the information for this window at once, with no recording session.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`debug-windows --window-id` exits 1 when no window has that ID.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Save the information for one window to a file: +
`aerospork debug-windows --window-id 1234 > window.txt`
