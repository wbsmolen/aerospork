// tag::purpose[]
:manpurpose: Print the environment that exec-* commands and callbacks run with
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork list-exec-env-vars [-h|--help] [--show-secrets]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`list-exec-env-vars` prints the environment that each of these starts from, one `NAME=value` line for each variable:

* The `exec-and-forget` command.
* The `on-focus-changed`, `on-focused-workspace-changed` and `on-focused-monitor-changed` callbacks.

AeroSpork adds `AEROSPORK_WINDOW_ID`, `AEROSPORK_WORKSPACE`, `AEROSPORK_FOCUSED_WORKSPACE` and `AEROSPORK_PREV_WORKSPACE` for each command, from what triggered it.
Those variables are not in this list.

By default, the command hides the value of each variable whose name looks like a secret: a name that contains `KEY`, `TOKEN`, `SECRET`, `PASSWORD`, `PASSWD`, `CREDENTIAL`, `AUTH` or `PRIVATE`.
The match is deliberately broad. A value that is hidden for no reason costs you one flag. A leaked credential costs you the credential.

The hiding is for the screen only. The script still receives the real values, because a script that posts to Slack needs its token. See aerospork-exec-and-forget(1).

Unlike the other query commands, `list-exec-env-vars` also works in the config, so a callback can print its own environment.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.
--show-secrets:: Print the real values in place of `<redacted>`.
