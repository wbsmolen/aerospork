= aerospork-fullscreen(1)
include::util/man-attributes.adoc[]
:manname: aerospork-fullscreen
// tag::purpose[]
:manpurpose: Toggle AeroSpork fullscreen for the focused window
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork fullscreen [-h|--help]     [--window-id <window-id>] [--no-outer-gaps]
aerospork fullscreen [-h|--help] on  [--window-id <window-id>] [--no-outer-gaps] [--fail-if-noop]
aerospork fullscreen [-h|--help] off [--window-id <window-id>] [--fail-if-noop]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`fullscreen` makes a window fill its monitor, in front of the other windows of the workspace.
The window keeps the outer gaps, and the menu bar and the Dock stay. The window also keeps its place in the tree.
This is AeroSpork fullscreen, not macOS fullscreen: no new Space opens. For macOS fullscreen, see `macos-native-fullscreen`.

When you focus another tiled window on the same workspace, the fullscreen window leaves fullscreen.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.
--no-outer-gaps:: Fill the monitor up to its edges, without the outer gaps. Incompatible with `off`.

--fail-if-noop::
include::util/fail-if-noop-flag-desc.adoc[]
Requires `on` or `off`.

--window-id <window-id>::
include::util/window-id-flag-desc.adoc[]

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

on:: Make the window fullscreen.
off:: Make the window leave fullscreen.

With neither argument, `fullscreen` toggles.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`fullscreen` exits 1 when no window is focused.
With `--fail-if-noop`, it also exits 1 when the window is already in the requested state.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Toggle fullscreen with a binding:
+
[source,toml]
----
[keys]
alt-f = 'fullscreen'
----
