= aerospork-move-node-to-workspace(1)
include::util/man-attributes.adoc[]
:manname: aerospork-move-node-to-workspace
// tag::purpose[]
:manpurpose: Move the focused window to another workspace
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork move-node-to-workspace [-h|--help] [--focus-follows-window] [--wrap-around]
                                 (next|prev)
aerospork move-node-to-workspace [-h|--help] [--focus-follows-window] [--fail-if-noop]
                                 [--window-id <window-id>] <workspace>

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`move-node-to-workspace` moves the focused window to `<workspace>`.
Focus stays on the workspace where it was, unless you give `--focus-follows-window`.
When no workspace has that name, AeroSpork creates it.

`next` and `prev` pick the workspace as `workspace next` and `workspace prev` do, and they read the list from stdin in the same way.
See aerospork-workspace(1).

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.
--wrap-around:: With `next` or `prev`, go on from the last workspace to the first, and the reverse.

--fail-if-noop::
include::util/fail-if-noop-flag-desc.adoc[]
Incompatible with `next` and `prev`.

--focus-follows-window::
Focus the window after the move. This has the same effect as `workspace <workspace>` after the move.

--window-id <window-id>::
include::util/window-id-flag-desc.adoc[]
Incompatible with `next` and `prev`.

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

(next|prev):: The next or the previous workspace.
<workspace>:: The name of the workspace to move the window to.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`move-node-to-workspace` exits 1 when no window is focused, and with `next` or `prev` when there is no next or previous workspace.
With `--fail-if-noop`, it also exits 1 when the window is already on `<workspace>`.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Send the focused window to workspace `3`, and go with it: +
`aerospork move-node-to-workspace --focus-follows-window 3`
* Send every new Mail window to workspace `3`, with a window rule:
+
[source,toml]
----
[on-window]
"com.apple.mail" = "move-node-to-workspace 3"
----
