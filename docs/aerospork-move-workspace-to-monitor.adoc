= aerospork-move-workspace-to-monitor(1)
include::util/man-attributes.adoc[]
:manname: aerospork-move-workspace-to-monitor
// tag::purpose[]
:manpurpose: Move the focused workspace to another monitor
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork move-workspace-to-monitor [-h|--help] [--workspace <workspace>] [--wrap-around] (left|down|up|right)
aerospork move-workspace-to-monitor [-h|--help] [--workspace <workspace>] [--wrap-around] (next|prev)
aerospork move-workspace-to-monitor [-h|--help] [--workspace <workspace>] <monitor-pattern>...

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`move-workspace-to-monitor` makes a workspace the visible workspace of another monitor, with all its windows.
Focus goes with the workspace.
Directions and `next`/`prev` count from the monitor that the workspace is on now: with `--workspace`, that is not always the focused monitor.

The command fails for a workspace that the config https://aerospork.app/docs/guide.html#assign-workspaces-to-monitors[pins to a monitor].

Old spelling, still accepted: `move-workspace-to-display`.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.
--wrap-around:: At the last monitor, go on to the first, and the reverse. Incompatible with `<monitor-pattern>`.

--workspace <workspace>::
include::util/workspace-flag-desc.adoc[]

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

(left|down|up|right)::
The nearest monitor in that direction from the monitor of the workspace.

(next|prev)::
The next or the previous monitor in monitor order, from the monitor of the workspace.
include::util/monitor-order.adoc[]

include::util/monitor-pattern-arg.adoc[]

// =========================================================== Exit status
include::util/exit-status.adoc[]

`move-workspace-to-monitor` exits 1 for a pinned workspace, when no monitor is in that direction or in that position, and when no pattern matches.
When the workspace is already on the target monitor, it exits 0.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Move the focused workspace to the next monitor, and wrap to the first: +
`aerospork move-workspace-to-monitor --wrap-around next`
* Move workspace `web` to the main monitor: +
`aerospork move-workspace-to-monitor --workspace web main`
