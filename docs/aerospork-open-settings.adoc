// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork open-settings [-h|--help]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`open-settings` opens the Settings window of AeroSpork and brings it to the front, even when another app is frontmost.
It does the same as *Settings…* in the menu bar icon, cmd-comma while AeroSpork is frontmost, or opening AeroSpork.app again while it runs.

There is only one Settings window. When it is already open, the command brings that window to the front.
AeroSpork never tiles the Settings window and never moves it to a workspace.

For the panes and how changes apply, see https://aerospork.app/docs/guide.html#settings-gui[the guide].

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`open-settings` exits 1 when the window does not open.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Open the Settings window with a binding:
+
[source,toml]
----
[keys]
alt-shift-comma = 'open-settings'
----
