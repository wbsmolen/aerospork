// tag::purpose[]
:manpurpose: Put every tiled window of the focused workspace in one container
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork flatten-workspace-tree [-h|--help] [--workspace <workspace>]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`flatten-workspace-tree` moves every tiled window of the workspace out of its nested container.
Each tiled window becomes a direct child of the root container, in tree order, and the empty containers go away.
The root container keeps its layout and orientation. Floating windows do not move.

Use it to reset a layout, when a reset is quicker than a repair by hand.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Given this layout
+
----
h_tiles
├── window 1
└── v_tiles
    ├── window 2
    └── window 3
----
+
`flatten-workspace-tree` gives this layout
+
----
h_tiles
├── window 1
├── window 2
└── window 3
----
