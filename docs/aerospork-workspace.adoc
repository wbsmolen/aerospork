= aerospork-workspace(1)
include::util/man-attributes.adoc[]
:manname: aerospork-workspace
// tag::purpose[]
:manpurpose: Focus a workspace
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork workspace [-h|--help] [--auto-back-and-forth] [--fail-if-noop] <workspace>
aerospork workspace [-h|--help] [--wrap-around] (next|prev)

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`workspace` focuses `<workspace>`, and the window on it that had focus last.
When no workspace has that name, AeroSpork creates it.
An off-screen workspace appears on the monitor that the config pins it to, else on the monitor where it was visible last, else on the main monitor.

`next` and `prev` focus the next or the previous workspace in a list:

* When stdin is not a terminal and holds more than white space, the list is the lines of stdin.
* In every other case, the list is the workspaces of the focused monitor in name order, with numbers in numeric order. It includes the empty workspaces that the config declares.

A workspace that the config declares always exists. Any other workspace exists only while it has windows or is visible.
For the details, see https://aerospork.app/docs/guide.html#persistent-workspaces[the guide].

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.
--wrap-around:: With `next` or `prev`, go on from the last workspace to the first, and the reverse.

--auto-back-and-forth::
When `<workspace>` is already focused, go to the previous workspace instead, as `workspace-back-and-forth` does.
Incompatible with `--fail-if-noop`.

--fail-if-noop::
include::util/fail-if-noop-flag-desc.adoc[]
Incompatible with `--auto-back-and-forth`, `next` and `prev`.

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

<workspace>:: The name of the workspace to focus.
(next|prev):: The next or the previous workspace in the list.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`workspace next` and `workspace prev` exit 1 when there is no next or previous workspace.
With `--fail-if-noop`, `workspace` also exits 1 when `<workspace>` is already focused.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Go to the next workspace that has windows, on the focused monitor: +
`aerospork list-workspaces --monitor focused --empty no | aerospork workspace next`
* Switch workspaces with bindings, and press the same key again to go back:
+
[source,toml]
----
[keys]
alt-1 = 'workspace --auto-back-and-forth 1'
alt-2 = 'workspace --auto-back-and-forth 2'
----
