= aerospork-list-modes(1)
include::util/man-attributes.adoc[]
:manname: aerospork-list-modes
// tag::purpose[]
:manpurpose: Print the binding modes of the config
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork list-modes [-h|--help] [--current]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`list-modes` prints the name of each binding mode in the config, one name for each line.
For how binding modes work, see https://aerospork.app/docs/guide.html#binding-modes[the guide].

include::util/cli-only.adoc[]

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.
--current:: Print only the active binding mode.

// =========================================================== Exit status
include::util/exit-status.adoc[]

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Show the active binding mode in a status bar: +
`aerospork list-modes --current`
