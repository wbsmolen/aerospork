:manpurpose: Run a shell script in the background, from the config

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
exec-and-forget <bash-script>   # config only, not available in CLI

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`exec-and-forget` runs `/bin/bash -c '<bash-script>'` and does not wait for it.
AeroSpork ignores the stdout, the stderr and the exit code of the script.

This command works only in the config, in a binding or a callback.
From a shell, run the script directly.

The script inherits the full environment of AeroSpork, *secrets included*: API tokens, credentials, and anything that your shell profile exported when AeroSpork started.
That is deliberate, because a script that posts to Slack needs its token.
It also means that the config is trusted input.

WARNING: Read every `exec-and-forget` line that you copy from the internet before you put it in your config.
The script runs as you, with your secrets.
Treat it as a line that you are about to paste into your shell.

AeroSpork adds these variables to the environment:

* `AEROSPORK_WINDOW_ID`: the target window, when the command has one.
* `AEROSPORK_WORKSPACE`: the target workspace, when the command has one.
* `AEROSPORK_FOCUSED_WORKSPACE`: in `on-focused-workspace-changed`, the workspace that now has focus.
* `AEROSPORK_PREV_WORKSPACE`: in `on-focused-workspace-changed`, the workspace that had focus before.

To start from an empty environment, set `inherit-env-vars = false` in `[exec]`.
To list the variables that the script receives, set `env-vars` in `[exec]`.
`aerospork list-exec-env-vars` prints the environment that every such script starts from.
It hides secret-looking values on screen, but the script still receives them.

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

<bash-script>::
The rest of the TOML string after `exec-and-forget `.
AeroSpork passes it to bash as it is, with no parsing and no escaping.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`exec-and-forget` exits 1 only when bash does not start. The exit code of the script does not count.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Open a new Terminal window with a binding:
+
[source,toml]
----
[keys]
alt-enter = 'exec-and-forget open -n /System/Applications/Utilities/Terminal.app'
----
