= aerospork-move-node-to-monitor(1)
include::util/man-attributes.adoc[]
:manname: aerospork-move-node-to-monitor
// tag::purpose[]
:manpurpose: Move the focused window to another monitor
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork move-node-to-monitor [-h|--help] [--window-id <window-id>] [--focus-follows-window]
                               [--wrap-around] (left|down|up|right|next|prev)
aerospork move-node-to-monitor [-h|--help] [--window-id <window-id>] [--focus-follows-window]
                               [--fail-if-noop] <monitor-pattern>...

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`move-node-to-monitor` moves the focused window to the visible workspace of another monitor.
Focus stays on the workspace where it was, unless you give `--focus-follows-window`.
You choose the monitor by direction, by order, or by pattern.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.
--wrap-around:: At the last monitor, go on to the first, and the reverse. Incompatible with `<monitor-pattern>`.

--focus-follows-window::
Focus the window after the move.

--fail-if-noop::
include::util/fail-if-noop-flag-desc.adoc[]
Works only with `<monitor-pattern>`.

--window-id <window-id>::
include::util/window-id-flag-desc.adoc[]

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

(left|down|up|right)::
The nearest monitor in that direction from the monitor of the window.

(next|prev)::
The next or the previous monitor in monitor order.
include::util/monitor-order.adoc[]

include::util/monitor-pattern-arg.adoc[]

// =========================================================== Exit status
include::util/exit-status.adoc[]

`move-node-to-monitor` exits 1 when no window is focused, when no monitor is in that direction or in that position, and when no pattern matches.
With `--fail-if-noop`, it also exits 1 when the window is already on the target monitor.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Send the focused window to the next monitor, and go with it: +
`aerospork move-node-to-monitor --wrap-around --focus-follows-window next`
