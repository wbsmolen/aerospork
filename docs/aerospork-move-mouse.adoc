= aerospork-move-mouse(1)
include::util/man-attributes.adoc[]
:manname: aerospork-move-mouse
// tag::purpose[]
:manpurpose: Move the mouse pointer to the focused window or monitor
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork move-mouse [-h|--help] [--fail-if-noop] <mouse-position>

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`move-mouse` moves the mouse pointer to the center of the focused window or of the focused monitor.
With a `lazy` position, the pointer moves only when it is outside the window or the monitor.

On an empty workspace no window has focus, so both `window-*` positions use the focused monitor.
Otherwise the pointer would stay on the monitor that you left.
In `on-focused-workspace-changed`, a callback is a list of commands with no shell `||`, so it needs that fallback built in.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

--fail-if-noop::
include::util/fail-if-noop-flag-desc.adoc[]
Works only with `window-lazy-center` and `monitor-lazy-center`.

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

<mouse-position>::
Where to move the pointer:
+
* `monitor-lazy-center`: the center of the focused monitor, unless the pointer is already on that monitor.
* `monitor-force-center`: the center of the focused monitor.
* `window-lazy-center`: the center of the focused window, unless the pointer is already inside that window.
* `window-force-center`: the center of the focused window.

// =========================================================== Exit status
include::util/exit-status.adoc[]

With `--fail-if-noop`, `move-mouse` exits 1 when the pointer is already inside the window or the monitor.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Make the mouse follow focus:
+
[source,toml]
----
on-focus-changed = ['move-mouse window-lazy-center']
----
