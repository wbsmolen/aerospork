= aerospork-macos-native-fullscreen(1)

// tag::purpose[]
:manpurpose: Toggle macOS fullscreen for the focused window
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork macos-native-fullscreen [-h|--help] [--window-id <window-id>]
aerospork macos-native-fullscreen [-h|--help] [--window-id <window-id>] [--fail-if-noop] on
aerospork macos-native-fullscreen [-h|--help] [--window-id <window-id>] [--fail-if-noop] off

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`macos-native-fullscreen` does what the green button of a window does: macOS moves the window to a fullscreen Space of its own.
AeroSpork takes the window out of the tiles while it is fullscreen, and puts it back in its place when it leaves fullscreen.

To fill the monitor and keep the window on its workspace, use `fullscreen` instead.

macOS reports the fullscreen state with a delay. Two `macos-native-fullscreen` commands in quick succession can act on the old state, or flicker.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

--fail-if-noop::
include::util/fail-if-noop-flag-desc.adoc[]
Requires `on` or `off`.

--window-id <window-id>::
include::util/window-id-flag-desc.adoc[]

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

on:: Make the window fullscreen.
off:: Make the window leave fullscreen.

With neither argument, the command toggles.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`macos-native-fullscreen` exits 1 when no window is focused.
With `--fail-if-noop`, it also exits 1 when the window is already in the requested state.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Toggle macOS fullscreen with a binding:
+
[source,toml]
----
[keys]
alt-shift-f = 'macos-native-fullscreen'
----
