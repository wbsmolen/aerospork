// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork list-windows [-h|--help] (--workspace <workspace>...|--monitor <monitor>...)
                       [--monitor <monitor>...] [--workspace <workspace>...]
                       [--pid <pid>] [--app-bundle-id <app-bundle-id>] [--format <output-format>]
                       [--count] [--json]
aerospork list-windows [-h|--help] --all [--format <output-format>] [--count] [--json]
aerospork list-windows [-h|--help] --focused [--format <output-format>] [--count] [--json]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`list-windows` prints one line for each window that matches every filter.
Give at least one of `--workspace`, `--monitor`, `--all` and `--focused`.
`--all` and `--focused` take no other filter.

include::util/cli-only.adoc[]

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

include::util/all-monitors-option.adoc[]

--focused::
Print the focused window. When no window has focus, the command exits 1.

--workspace <workspace>...::
Print only the windows on the given workspaces.
`<workspace>...` is a space-separated list of:
+
* A workspace name.
* `focused`: the focused workspace.
* `visible`: every visible workspace, one for each monitor.

include::util/monitor-option.adoc[]

--pid <pid>:: Print only the windows of the app with this process ID.

--app-bundle-id <app-bundle-id>::
Print only the windows of the app with this https://developer.apple.com/documentation/appstoreconnectapi/bundle_ids[bundle ID].
+
Old spelling, still accepted: `--app-id`.

include::util/exit-status.adoc[]

`list-windows --focused` exits 1 when no window has focus.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Print the windows of the focused workspace: +
`aerospork list-windows --workspace focused`
* Print the ID of the focused window: +
`aerospork list-windows --focused --format '%{window-id}'`
* Count the Safari windows on every monitor: +
`aerospork list-windows --monitor all --app-bundle-id com.apple.Safari --count`
* Print every window as JSON, with its workspace: +
`aerospork list-windows --all --json --format '%{window-id} %{app-name} %{window-title} %{workspace}'`
