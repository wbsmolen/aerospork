= aerospork-enable(1)
include::util/man-attributes.adoc[]
:manname: aerospork-enable
// tag::purpose[]
:manpurpose: Enable or disable window management
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork enable [-h|--help] toggle
aerospork enable [-h|--help] on [--fail-if-noop]
aerospork enable [-h|--help] off [--fail-if-noop]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`enable off` stops window management: AeroSpork moves the windows of off-screen workspaces onto the screen and stops every binding.
`enable on` starts window management again, in the `main` binding mode.
The *Pause tiling* and *Resume tiling* items of the menu bar icon do the same.

While window management is off, AeroSpork rejects every other command, query commands included.
Such a command exits 1 with the message `server is disabled and doesn't accept commands`.
`-h`, `--help`, `-v` and `--version` still work.

WARNING: No binding works while window management is off, so a binding cannot run `enable on`.
Run `aerospork enable on` from a terminal, or choose *Resume tiling* from the menu bar icon.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

--fail-if-noop::
include::util/fail-if-noop-flag-desc.adoc[]
Incompatible with `toggle`.

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

on:: Enable window management.
off:: Disable window management.
toggle:: Enable window management if it is off, and disable it if it is on.

// =========================================================== Exit status
include::util/exit-status.adoc[]

With `--fail-if-noop`, `enable on` exits 1 when window management is already on, and `enable off` exits 1 when it is already off.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Let a script pause tiling while it arranges windows itself:
+
----
aerospork enable off
# ...
aerospork enable on
----
