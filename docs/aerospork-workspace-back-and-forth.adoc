// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork workspace-back-and-forth [-h|--help]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`workspace-back-and-forth` focuses the workspace that had focus before the focused one.
Run it twice to go back to where you started.

Unlike `focus-back-and-forth`, it still works after you close windows, because a workspace keeps its name even when it is empty.
It fails when there is no previous workspace yet, for example just after AeroSpork starts.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`workspace-back-and-forth` exits 1 when there is no previous workspace yet.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Go back and forth with one key:
+
[source,toml]
----
[keys]
alt-tab = 'workspace-back-and-forth'
----
