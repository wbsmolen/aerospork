= AeroSpork commands
include::util/site-attributes.adoc[]

include::util/header.adoc[]

Run each command from a terminal as `aerospork <command>`, or from a binding or a callback in the config without the `aerospork` prefix.
The query commands work only from the CLI, except `list-exec-env-vars`. `exec-and-forget` works only in the config.
Every command exits with one of the codes in <<exit-status>>.
Each command also has a man page: run `man aerospork-<command>`.

In this reference, a _node_ is a window or a container in the tree. In practice, the commands move windows.

[#query-commands]
== Query commands

Query commands print the state of AeroSpork and change nothing.
They work only from the CLI, because a binding or a callback has no way to use their output.
`list-exec-env-vars` is the exception: it also works in the config, so a callback can print its own environment.
