// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork split [-h|--help] [--window-id <window-id>] (horizontal|vertical|opposite)

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`split` exists only for compatibility with i3. Use `join-with` unless you have a reason not to.
With https://aerospork.app/docs/guide.html#normalization[`enable-normalization-flatten-containers`] on, `split` fails. `join-with` works with it on.

When the parent container of the focused window has more than one child, `split`:

. Creates a new `tiles` container with the orientation that the argument gives.
. Puts the new container in the place of the focused window.
. Puts the focused window into the new container, as its only child.

When the focused window is the only child of its parent container, `split` changes the orientation of that container.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

--window-id <window-id>::
include::util/window-id-flag-desc.adoc[]

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

horizontal:: A horizontal container.
vertical:: A vertical container.
opposite:: The opposite orientation of the parent container.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`split` exits 1 with `enable-normalization-flatten-containers` on, when no window is focused, and for a floating window.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Split the focused window vertically: +
`aerospork split vertical`
