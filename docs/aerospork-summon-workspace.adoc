= aerospork-summon-workspace(1)

// tag::purpose[]
:manpurpose: Bring a workspace to the focused monitor

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospork summon-workspace [-h|--help] [--fail-if-noop] <workspace>

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
`summon-workspace` makes `<workspace>` the visible workspace of the focused monitor, and focuses it.
`workspace` goes to the monitor of a workspace. `summon-workspace` brings the workspace to you.

When `<workspace>` is visible on another monitor, the two monitors swap workspaces, so nothing that was on the screen disappears.
On one monitor, `summon-workspace` does the same as `workspace`.

The command fails for a workspace that the config https://aerospork.app/docs/guide.html#assign-workspaces-to-monitors[pins to another monitor].

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help and exit.

--fail-if-noop::
include::util/fail-if-noop-flag-desc.adoc[]

// =========================================================== Arguments
include::util/conditional-arguments-header.adoc[]

<workspace>:: The name of the workspace to bring.

// =========================================================== Exit status
include::util/exit-status.adoc[]

`summon-workspace` exits 1 for a workspace that is pinned to another monitor.
With `--fail-if-noop`, it also exits 1 when the workspace is already visible on the focused monitor.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Bring workspace `web` to the monitor that you work on: +
`aerospork summon-workspace web`
